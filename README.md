# Computational Analysis of h-BN and Silicon Crystal Structures

## Overview

This project presents a computational materials science workflow for analyzing and visualizing crystal structures of:

- Hexagonal Boron Nitride (h-BN)
- Silicon (Si)

using Python-based scientific computing libraries.

The project focuses on:
- crystal structure visualization
- structural analysis
- symmetry analysis
- scientific plotting
- supercell generation
- defect modeling
- surface analysis
- computational crystallography

The workflow was developed as a research-oriented portfolio project for computational materials science and condensed matter physics applications.

---

# Project Objectives

The main objectives of this project are:

- Learn computational materials science workflows
- Analyze crystal structures using Python
- Understand crystallographic properties
- Perform structural and symmetry analysis
- Visualize materials scientifically
- Investigate defects and surfaces

---

# Materials Investigated

## 1. Hexagonal Boron Nitride (h-BN)

h-BN is a layered wide-bandgap material with strong in-plane bonding and excellent thermal stability.

Applications include:
- nanoelectronics
- 2D materials research
- insulating substrates
- thermal management

---

## 2. Silicon (Si)

Silicon is one of the most important semiconductor materials used in modern electronics.

Applications include:
- transistors
- integrated circuits
- solar cells
- semiconductor devices

# Project Workflow

The project was organized into multiple computational notebooks.

| Notebook | Description |
|---|---|
| 01_structure_loading.ipynb | Loading and inspecting CIF crystal structures |
| 02_visualization_molecules.ipynb | Visualization of atomic structures |
| 03_structural_analysis.ipynb | Structural and crystallographic analysis |
| 04_scientific_visualization.ipynb | Scientific plotting and comparative visualization |
| 05_advanced_crystallography.ipynb | Supercells, symmetry, and primitive cell analysis |
| 06_defects_and_surfaces.ipynb | Vacancy defects and surface slab generation |
| 07_project_summary.ipynb | Final project summary and scientific discussion |

- planar vs tetrahedral coordination
